A fictional Italian restaurant example built to demonstrate a restaurant website, menu, cart, checkout summary, and table reservation form.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install` in this folder.
3. Run `npm start` and open <http://localhost:3000>.

Reservations submitted through the local server are stored in SQLite. When the site is hosted statically, the form provides a phone handoff using the demo contact details. The checkout page is a sample flow and does not send orders or process payments.
